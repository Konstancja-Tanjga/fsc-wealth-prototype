# FSC Wealth Advisor · Client 360 concept

Clickable prototype of a wealth-management workspace in Salesforce Financial Services Cloud, with Agentforce meeting preparation. Styled after the open-source Salesforce Lightning Design System 2 (SLDS 2). All people, companies and amounts are fictional.

Demo path: Advisor Home → Client 360 → Ask Agentforce (meeting brief, options, action plan) → Household → Financial Account.

- Static site, no build step: `index.html`.
- Figma source (screens, docs, handoff specs): FSC file, page "Screens".
- Independent concept by Konstancja Tanjga-Nawrot. Financial Services Cloud and Agentforce are Salesforce products; this is not a Salesforce product.
